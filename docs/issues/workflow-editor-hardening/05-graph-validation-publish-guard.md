## What to build

增强流程校验能力，从简单字段校验升级为图结构校验。编辑器应识别孤立节点、从开始节点不可达的节点、无法到达结束节点的节点、无效分支和关键配置缺失。发布或启用前必须通过关键校验，失败时阻止发布并给出可定位原因。

## Acceptance criteria

- [x] 校验从开始节点正向遍历，识别不可达节点。
- [x] 校验从结束节点反向遍历，识别无法走到结束节点的节点。
- [x] 校验识别没有任何有效入边和出边的孤立节点。
- [x] 校验识别普通审批节点缺少审批对象。
- [x] 校验识别条件网关没有有效分支。
- [x] 校验识别分支缺少表达式、目标节点不存在或源节点不是条件网关。
- [x] 校验识别开始节点被连入、结束节点继续连出等非法关系。
- [x] 校验结果在右侧校验面板中清晰展示，并能表达严重程度。
- [x] 有问题的节点或连线在画布上有可见提示。
- [x] 发布/启用前存在关键校验失败时，阻止发布并展示失败原因。
- [x] 项目构建通过。
