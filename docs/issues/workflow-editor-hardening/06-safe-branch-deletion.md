# Issue 06: 实现复杂分支和条件网关删除策略

## What to build

把当前直接删除节点/连线的行为升级为安全删除策略。特别是删除分支连线和条件网关时，系统需要展示影响范围，并让用户选择只删除连接关系还是删除该分支后续节点。开始节点和结束节点应被保护，避免破坏流程骨架。

## Acceptance criteria

- [x] 删除开始节点或结束节点时被阻止，并提示原因。
- [x] 删除普通节点时删除其关联连线，并触发校验刷新。
- [x] 删除分支连线时弹出确认，支持 `仅删除连线`。
- [x] 删除分支连线时支持 `删除该分支及后续节点`，并展示将被删除的节点数量。
- [x] 删除条件网关时弹出确认，展示受影响分支数量和下游节点数量。
- [x] 删除条件网关时用户可以取消操作。
- [x] 删除后不会留下指向不存在节点的连线。
- [x] 删除后校验面板能识别新产生的不可达或孤立节点。
- [x] 删除行为进入撤销/重做历史。
- [x] 项目构建通过。
